# Privacidade e publicação

Este repositório contém informações de agenda associadas a uma autoridade pública.

- Utilize, preferencialmente, um repositório GitHub **privado**.
- Não ative GitHub Pages, publicação pública ou indexação externa sem autorização.
- Antes de compartilhar o repositório, revise os dados de voos, hospedagem e horários.
- Quando necessário, remova ou reduza detalhes operacionais antes de qualquer divulgação ampla.
